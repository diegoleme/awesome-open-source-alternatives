## AI Assistants and Coding

### [Character.ai](https://character.ai)
- [SillyTavern](https://github.com/SillyTavern/SillyTavern) - Needs a local model or an LLM API.

### [ChatGPT](https://chatgpt.com) / [Claude](https://claude.ai)
- [Ollama](https://github.com/ollama/ollama) - Run open models locally. Local models are below frontier quality and need a good GPU.
- [Open WebUI](https://github.com/open-webui/open-webui) - Chat interface for Ollama and OpenAI-compatible APIs.

### [Gamma](https://gamma.app)
- [Presenton](https://github.com/presenton/presenton)

### [GitHub Copilot](https://github.com/features/copilot) / [Cursor](https://cursor.com)
- [Continue](https://github.com/continuedev/continue)
- [Tabby](https://github.com/TabbyML/tabby) - Self-hosted; needs a GPU for good performance.

### [Lovable](https://lovable.dev) / [Bolt](https://bolt.new) / [v0](https://v0.dev)
- [bolt.diy](https://github.com/stackblitz-labs/bolt.diy)

### [NotebookLM](https://notebooklm.google)
- [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)
- [Open Notebook](https://github.com/lfnovo/open-notebook)

### [Perplexity](https://perplexity.ai)
- [Vane](https://github.com/ItzCrazyKns/Vane) - Formerly Perplexica. Pair it with [SearXNG](https://github.com/searxng/searxng) for search.

- [Kortix](https://github.com/kortix-ai/suna) - The open-source CompanyOS: agents, skills, memory and connectors in one git repo you own, with each session on its own cloud computer. Open source, any model, on your infrastructure or ours.

## Contributing

Pull requests are welcome. To keep the list useful:

1. **Open source only.** The project must have public source code under an [OSI-approved license](https://opensource.org/licenses). Note any licensing caveat (fair-code, open core, paid features).
2. **Real alternatives.** It must replace the paid app. CLIs or SDKs for a paid service don't count.
3. **Maintained and used.** No archived repos or repos without commits in the last year. Brand-new projects with very few users may be asked to come back later.
4. **Link to the source repository**, not the marketing site.
5. **Format.** Use `- [Name](repo-link) - Optional short description.`, alphabetical within each app. New apps go under the right category, alphabetical, with a matching entry in [Contents](#contents).
6. **Disclose affiliation** in the PR description if you work on the project.
